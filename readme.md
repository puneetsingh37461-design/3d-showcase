# Interactive 3D Product Showcase
GDG-USAR Tech Team task: Web Development, Interactive 3D Product Showcase.

Open `index.html` in a browser (internet needed for the 3D library and model).
- Rotate: drag. Zoom: scroll / pinch.
- Buttons: Front, Back, Close-up move the camera and show product info.
- Animations: auto-rotation, smooth camera moves, fade-in info text.
- Responsive: stacked on mobile, side by side on desktop.

Built with HTML, CSS, JavaScript and Google's `<model-viewer>`.
